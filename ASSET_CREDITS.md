## Original AI-generated editorial concepts

Created for Gibraltar For Sale with Manus image generation on 9 November 2026. These are illustrative concepts, not photographs of real Gibraltar properties or actual available homes. Visible captions say so wherever displayed.

- `concept-living-room.webp` — considered Mediterranean living-room mood.
- `concept-terrace.webp` — light, materials and outdoor-space mood.
- `concept-courtyard.webp` — restrained courtyard / architecture mood.
- `concept-planning.webp` — home-search planning still life; not a real document or financial calculation.
- `concept-bedroom.webp` — bedroom mood; not a rental or sale listing.

The `-900.webp` files are smaller responsive derivatives of the same source. Original generated masters remain in `assets/generated/`.

## Integrity and display rules

- Every location photo caption states when it is broad location context rather than a specific area property.
- AI-generated property scenes must carry a visible “AI-generated concept image; not a real property listing” note.
- Never use search-result thumbnails, watermarked previews, Dreamstime, Shutterstock or Alamy assets without a separate valid licence.
- Keep these creator/source/license links intact when moving or replacing an image. For ShareAlike images, preserve the listed share-alike license for the adapted image file.
